
# 🚖 Uber 

## 📌 Project Overview

This project is a multi-page interactive Power BI dashboard built on Uber ride data to analyze business performance, revenue trends, customer behavior, and vehicle efficiency.

The dashboard simulates a real-world analytics solution that could be used by Uber management teams for data-driven decision making.

--- 
### 🎯 Project Objectives

Analyze ride performance across vehicle types

Understand revenue trends (monthly / quarterly)

Track completed vs cancelled vs lost bookings

Study customer behavior & loyalty

--- 
### 🧰 Tools & Technologies Used

Power BI Desktop

DAX (Data Analysis Expressions)

Excel / CSV Dataset

Data Modeling
